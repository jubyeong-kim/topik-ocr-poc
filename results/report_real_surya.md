## 관찰

**1. 정답 전사의 한계로 점수가 낮게 나왔다.**
`line04`·`line06`·`line07`·`line08`·`line10` 의 차이 상당 부분이 **따옴표**다.
정답 전사에서 따옴표를 제외했는데 surya 는 이를 정확히 인식해 오히려 감점됐다.
`line07` 은 `'` 하나 차이로 CER 0.05 이므로, 실제 성능은 측정치보다 좋다.

**2. 어절 구조가 유지된다.**
easyocr 이 `기출문제를` → `기 출문 제틀` 로 어절을 붕괴시킨 것과 달리,
surya 는 어절을 유지한 채 **개별 글자만 드물게 틀린다** (`기출`→`기童`, `선생님`→`선범님`).
사람이 읽고 고치기에 훨씬 유리한 형태다.

**3. 띄어쓰기가 주요 실패 요인이다.**
`요.즉학원에서`(붙임), `수업시간`(붙임) 처럼 공백 처리에서 실패가 발생한다.
띄어쓰기를 정규화해 재계산하면 일치율이 오를 여지가 있다.

## 재현 방법

Colab (GPU 런타임)에서:

```bash
git clone https://github.com/jubyeong-kim/topik-ocr-poc.git
cd topik-ocr-poc
pip install -q easyocr "surya-ocr==0.17.1" "transformers<5"
curl -sL -o data/real/002_demo.jpg https://raw.githubusercontent.com/Nexdata-AI/5711-Images-Korean-Handwriting-OCR-data/main/002_demo.jpg
python prepare_real.py
python poc.py run --data data/real --engine surya --out results/report_real_surya.md
```

⚠️ **버전 주의**
- surya `0.20+` 는 모든 추론 백엔드가 외부 서버·컨테이너 기반(vLLM=Docker 등)이라 Colab 에서 실행 불가
- surya `0.17.1` 은 `transformers 5.x` 와 충돌 (`SuryaDecoderConfig has no attribute pad_token_id`) → `transformers<5` 고정 필요
